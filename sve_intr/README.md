# KRYSTALS-KYBER
## Overview
### PQC
A type of cryptography that is designed to be resistant to attacks from both classical and quantum computers
### ARM SVE
The new vector extension from ARM that is designed to be vector length agnostic, actual lengths varying from 128 to 2048 bits. Allows the same code to be run on successive generations of hardware without modifications or recompiling.
### Rust
A memory safe language that just works.
## Dependancies
This project uses
- GNU Make
- Arm GNU toolchain for Linux
- QEMU
